# 无限人族进化 · 开发日志

《无限人族进化》是一款开发中的原创无限流动作 RPG。玩家从归航站进入规则各异的世界，探索、战斗，并将能力带回下一段旅程。首发 V1 计划包含灰巢设施、雾港余烬和钟骨工厂。

**项目状态：开发中；目前没有公开可玩的版本、试玩包或发行日期。** 这个仓库只发布经核实的开发进度并收集反馈，不包含游戏源码、设计原件、图片、音频或安装包。

## 开发方向

- Windows 桌面应用：Tauri 2，Rust 负责玩法状态与存档。
- 画面：TypeScript、PixiJS 8、固定斜视角 2.5D；地图使用 Tiled 制作。
- 三个世界有不同的探索、战斗和环境规则，玩家在归航站整理能力并选择下一段旅程。

这些是产品方向，不能视为已完成的可玩内容。
